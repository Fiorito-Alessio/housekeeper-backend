# Roadmap
This file describes all the ideas for HouseKeeper application.

## V1

 - Account creation
 - Household creation
 - Household invite with a link
 - Task management: create, edit and delete tasks
 - Assign a task to a member or share it with the whole household
 - Mark a task as done

## Future ideas

 - Account verification by email
 - Recurring tasks
 - Gamification: xp reward on completing a task, level system...
 - Notifications: email, discord...
 - Shared expenses management
 - Shared calendar
 - Leaving notes
